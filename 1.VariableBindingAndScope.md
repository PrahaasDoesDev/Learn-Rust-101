## Mutable 

In Rust we use `mut` to mark a variable as mutable, because in rust a variable is immutable by nature. 

```rust
fn main() {
    let mut x = 1;
    x += 2; // since we are changing the value of x it has to be mutable.
    // x+=2 is the shorthand notation for x=x+2;
    assert_eq!(x,3);
    println!("Success");
}

```

## Scope

A scope is the range within the program for which the item is valid

```rust
fn main() { //Outer Scope

    let x: i32 = 10; // over here we are initialising the variable x with the  value of 10 of integer type.
    { //Inner Scope
        let y: i32 = 5;
        println!("The value of x is {} and the value of y is {}" , x , y);
    } //Inner scope

    println!("The value of x is {} and the value of y is {}", x,y);
} //Outer Scope
```
The above program won't compile is because a variable is only valid inside the scope which it was decalred.

Here the variable y is defined inside a scope and is valid inside its scope only.

### Corrected Program:
```rust
fn main() { //Outer Scope

    let x: i32 = 10; // over here we are initialising the variable x with the  value of 10 of integer type.
    let y: i32 = 5;
    { //Inner Scope
        println!("The value of x is {} and the value of y is {}" , x , y);
    } //Inner scope

    println!("The value of x is {} and the value of y is {}", x,y);
} //Outer Scope
```

## Shadowing

You can declare a new variable with the same name as a previous variable, then we can say the first variable is shadowed by the second variable 

```rust
fn main() {
    let x: i32 = 5;
    {
        let x = 12;
        assert_eq!(x,5);
    }
    assert_eq!(x,12);

    let x = 42; // Over here we are shadowing the value of x in the main scope meaning we redeclare and reinitialise the variable x again with the integer type


    println!("{}" , x);  //Prints 42

    //Finally this outputs: 42
}
```

## Unused variables

```rust 
fn main(){
    let x = 1;

}
//Warning: Unused variable x
```
To ignore this warning in Rust we use ` _ `

```rust 
fn main(){
    let _x = 1;
}

// No Working outputted here
```

Or we can mention at the top of the document the following statement:
`#[allow(unused_variables)]`

```rust 
#[allow(unused_variables)]
fn main(){
    let x = 1;

}

// No warning outputted here
```

## Destructuring
We can use pattern with `let` to destruct a tuple to seperate variables.

```rust
fn main() {
    let (mut x,y) =  (1,2);
    //This is called destructing, where we are assigning x the value of 1 and y the value of 2.

    x += 2;
    //Since we declared mut before x we can now change the value of x while the value of y is the same constant 2.


    assert_eq!(x, 3);
    assert_eq!(y, 2);

    println!("Success");
}
```

## Destructuring Assignments
This was introduced in Rust 1.59, where we can use tuples, slice and struct patterns as the left hand side of an assigment.


```rust
fn main() {
    let (x,y);
    //Declaring two variables at once.

    //We dont need to use the let keyword again because we have already assigned it above.

    (x,..) = (3,4);
    // .. is basically used to simply ignore the value and we dont care about that value
    [..,y] = [1,2];
    //Similarly we dont care about the first value here and then we assign the second variable.
    
    assert_eq!([x,y], [3,2]);
    //X = 3, y=2
    println!("Success");
}
```
